# Web版（iPhone・ブラウザ）の使い方と初期設定

Web版は `https://kiwiman0706-beep.github.io/MeishiApp/` で動く、ホーム画面に置けるWebアプリ（PWA）です。
App Storeを通さず、iPhoneでもAndroid・PC版と同じ画面とデータ（Googleドライブの Theta Vault）を使えます。

## 1. iPhoneのホーム画面に置く

1. iPhoneの **Safari** で上のアドレスを開きます。
2. 共有ボタン →「ホーム画面に追加」。
3. ホーム画面の「名刺Hatch」から起動します（全画面のアプリとして開きます）。

メニュー →「Gemini APIキー・モデル」でキーを入れると、撮影した名刺を読み取れます（Android版と同じキーで構いません）。
ここまではGoogleの設定なしで使えます。データはこのiPhoneのSafariの中に保存されます。

## 2. Googleドライブ同期・Google連絡先を使う（1回だけ、PCで10分ほど）

Android版の設定（`DRIVE_SETUP.md`）で作ったGoogle Cloudのプロジェクトに、**Web用のOAuthクライアント**を1つ足します。

1. https://console.cloud.google.com/ で、名刺用のプロジェクトを開きます。
2. 「APIとサービス」→「ライブラリ」で、次の2つを「有効にする」：
   - **Google Drive API**（Android版で有効にしてあれば不要）
   - **Google People API**（連絡先）
3. 「OAuth同意画面」（Google Auth Platform）→「データアクセス」→「スコープを追加」で
   `.../auth/drive` と `.../auth/contacts` を追加（無くても動きますが、許可画面の説明が正しくなります）。
   テストユーザーに自分のGoogleアカウントが入っていることを確認します。
4. 「クライアント」→「クライアントを作成」：
   - アプリケーションの種類：**ウェブ アプリケーション**
   - 名前：`Theta Meishi Hatch Web` など
   - **承認済みの JavaScript 生成元**：`https://kiwiman0706-beep.github.io`
   - リダイレクトURIは不要です。
5. 作成すると「クライアントID」（`123456-xxxx.apps.googleusercontent.com`）が出ます。クライアントシークレットは使いません。

iPhoneのWeb版で：

1. メニュー →「Googleアカウント」→ クライアントIDを貼り付けて「保存」→「Googleにログイン」。
2. 「このアプリはGoogleで確認されていません」と出たら「続行」（自分で作ったアプリのため）。ドライブと連絡先を「許可」。
3. メニュー →「Google Driveで同期を始める」。Android版・PC版と同じ「マイドライブ/Theta Vault」を使います。
   初回は名刺のノートだけを受け取り、名刺の画像は表示したときに取りに行きます。

## 注意

- **ログインは約1時間で切れます**。iPhoneでは、ボタンを押したときにしかGoogleのログイン画面を開けないため、切れたらホーム画面の「Googleにログイン」を押してください。
  ログインしていない間に読み取った名刺の連絡先登録は、次にログインしたときにまとめて行います。
- **バックグラウンドでは動きません**。読み取り・同期はアプリを開いている間に進みます。
- **ホーム画面ウィジェット・録音・Googleカレンダー登録・会社サイトからのロゴ取得はありません**（ロゴは名刺から切り出します。サイトからの取得は他の版で行えば同期で届きます）。
- 名刺の撮影は普通の写真です（Android版のような自動の切り抜きはありません）。表裏は「まとめて撮影」で写真を選んで取り込みます。
- データはSafariのWebサイトデータとして保存されます。Safariの「履歴とWebサイトデータを消去」で消えるので、Googleドライブ同期をおすすめします。
- 新しい版は、開いたときに自動で入れ替わります（次に開いたときから新しい版）。
