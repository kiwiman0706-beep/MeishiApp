# 0.2.0 スキャン撮影の検証記録

## 実施した検証

- Gradle 8.9 / AGP 8.7.3 / Android SDK35 / ML Kit Document Scanner 16.0.0でreleaseビルド成功。releaseの必須Lintチェックを通過。
- 同梱のbuild.shでAPKを生成し、zipalign・apksignerのv2/v3署名検証に合格。0.1.0と署名証明書SHA-256が一致。packageを維持しversionCode2 / versionName0.2.0を確認。
- Android取込・バックアップ・スキャン順序テストのテストAPKをコンパイル・署名できることを確認（端末上では未実行）。

- Playwrightでスキャン開始要求を検証：新規の全ページ1人・1ページ1人・表裏2ページ1人、既存人物への追加、通常カメラへの切り替え。ファイル取り込みのまとめ方とは独立していることを確認。
- 既存の一覧・検索・表表示・編集保存・画像取込・CSV要求・HTMLエスケープの回帰テストに合格。
- 320/360/393/768pxの画面幅でスキャン案内を含むレイアウトを確認。日本語フォントで画像確認。
- JavaScriptとビルドスクリプトの構文確認。

## 実機で未確認の項目

この環境ではGoogle Play開発者サービス搭載の実機を操作できないため、**実カメラでの輪郭検出・スキャン画面の初回ダウンロード・Google側のスキャンUI・撮影結果の返却は未検証**です。UIテストではNative bridgeをモックしています。実カメラの動作確認と同等ではありません。

実機では次を確認してください。

1. 0.1.0をアンインストールせず0.2.0を上書きし、既存の名刺・メモ・録音が残ること。
2. 「取り込み → スキャン撮影 → スキャンを開始」。初回ダウンロード後にカメラが開くこと。
3. 表→裏を撮影し、補正範囲と向きを確認して完了。1人に2ページ保存され、再起動しても画像が残ること。
4. 表裏2人分の4枚を撮影して2人に分かれること。スキャン画面で順番を変えた場合は、その最終順になること。
5. 詳細の「スキャンで追加」で既存人物に追加できること。キャンセルではデータが増えないこと。
6. スキャナが使えない端末・通信失敗では通常のカメラに切り替えられること。
7. 保存したスキャン画像でGemini認識・連絡先登録・バックアップができること。

`tests/android/Smoke.java` に、ファイル名の逆順で返されたスキャン結果を表裏2ページ単位で取り込むテストを追加しました。Android実行環境がないため、実行済みとはしていません。実行時は空の隔離エミュレータを使用してください。

## 実機で必ず確認する項目

以下は実装済みですが、実機・実アカウント・APIキーを使った接続確認はしていません。

1. APKのインストール・起動、日本語入力、Androidの戻る操作、キーボードと画面端の余白。
2. 1枚撮影→裏面追加→アプリを閉じて再起動しても画像が残る。
3. ScanSnapのサンプル画像・PDFを2～3件取り込み、表裏の組み合わせを確認。
4. ご自身のAPIキーを設定し、利用可能モデルを選択→Gemini認識→結果確認→保存。
5. まずテスト名刺1人だけGoogle連絡先に登録し、選んだアカウントへ同期されるか確認。
6. 名刺画像が連絡先の写真に入るか、実際の着信画面でどのように表示されるか確認。
7. 10秒程度録音し、停止・再生・シーク・画面消灯中の録音と通知停止を確認。
8. CSVをExcelで開く。Google DriveへバックアップZIPを保存し、アップロード完了をDriveアプリで確認。
