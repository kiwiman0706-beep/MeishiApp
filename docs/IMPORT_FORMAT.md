# インポートファイルの仕様（Eightなどからの移行用）

Meishi-Claudeの「メニュー → Eightなどからインポート」で読み込むファイルの形式です。

## 全体の形

**ZIPファイル1つ**の中に、**CSVを1つ**と**名刺画像**を入れます。

```
meishi-import.zip
├── cards.csv          ← 名刺の項目（1行 = 1人）
└── images/            ← 名刺画像（フォルダ名は自由）
    ├── 00001.jpg
    ├── 00002.jpg
    └── …
```

- CSVのファイル名は自由です。ZIPの中に複数ある場合は `cards.csv` を優先します。
- 画像の置き場所は自由です。CSVには **CSVファイルから見た相対パス** を書きます（例：`images/00001.jpg`）。大文字小文字の違いや `\` 区切りでも見つけます。
- 同梱スクリプト `tools/make_meishi_import.py` を使うと、この形式を自動で作れます（後述）。

## CSV

| 項目 | 内容 |
| --- | --- |
| 文字コード | UTF-8（BOMあり・なし）または Shift_JIS。自動で判別します |
| 区切り | カンマ。値にカンマや改行を含む場合は `"` で囲む（Excelの「CSV」保存のままで可） |
| 1行目 | 見出し（列名）。**列の順番は自由**。知らない列は無視します |
| 2行目以降 | 1行 = 1人 |
| 上限 | 20,000行。ZIP全体で4GB、画像1枚100MBまで |

### 列名（見出し）

次の表のどれかの名前で書けば認識します。全角・半角、大文字小文字、空白、（）の全角半角の違いは無視します。

| アプリの項目 | 使える列名 |
| --- | --- |
| 氏名 | 氏名 / 名前 / フルネーム / name |
| 姓・名（分かれている場合） | 姓 / lastname と 名 / firstname → 「姓 名」に結合 |
| ふりがな | ふりがな / フリガナ / よみ / 氏名(カナ) |
| ふりがな（分かれている場合） | 姓(カナ) / セイ と 名(カナ) / メイ |
| 会社・組織 | 会社名 / 会社 / 組織 / 組織名 / 所属 / company |
| 部署 | 部署名 / 部署 / 部門 / department |
| 肩書き | 役職 / 役職名 / 肩書き / 肩書 / title |
| メール | e-mail / email / メール / メールアドレス |
| 電話 | 電話番号 / 電話 / TEL / TEL会社 / TEL部門 / TEL直通 / 代表電話 / 直通電話 |
| 携帯電話 | 携帯電話 / 携帯 / 携帯番号 / mobile |
| FAX | FAX / FAX番号 |
| 郵便番号 | 郵便番号 / 〒 |
| 住所 | 住所 / 所在地 / 都道府県 / 市区町村 / 住所1 / 住所2 / 番地 / 建物名（複数あれば順に結合） |
| Webサイト | URL / Webサイト / ホームページ |
| タグ | タグ / 分類 / グループ |
| 名刺交換日 | 名刺交換日 / 交換日 / 出会った日 / 登録日（`2024/3/5`、`2024年3月5日`、`2024-03-05` など） |
| 交換場所 | 交換場所 / 出会った場所 / 場所 |
| メモ | メモ / 備考 / コメント（やり取りのメモとして追加） |
| **表面画像** | 表面画像 / 表画像 / 表面 / 画像 / 画像1 / front |
| **裏面画像** | 裏面画像 / 裏画像 / 裏面 / 画像2 / back |
| 追加画像 | 追加画像 / 画像3 / 画像4 |
| 識別ID（任意） | ID / 名刺ID / カードID |

- 同じ項目に当たる列が複数ある場合（TEL会社とTEL直通など）は、改行でつないで1項目に入れます。
- 画像はJPEG・PNG・WebP・HEIC・PDFが使えます。PDFは全ページを取り込みます。

## 取り込み時の動き

| 行の状態 | 動き |
| --- | --- |
| 氏名あり | CSVの内容をそのまま登録し「確認済み」。画像は名刺画像として保存（Geminiには送りません） |
| 氏名なし・画像あり | 画像を保存し、バックグラウンドでGeminiが読み取ります |
| 「Google連絡先にも登録する」をオン | 氏名のある人を、バックグラウンドでGoogle連絡先に登録します（重複は後で一覧に出ます） |
| 同じZIPをもう一度読み込んだ | 取り込み済みの人は追加しません |

二重取り込みの判定は、「識別ID」列があればその値、無ければ「氏名＋会社＋メール＋表面画像のファイル名」で行います。

**EightからGoogle連絡先へ既に同期している場合は、「Google連絡先にも登録する」をオフのまま**取り込んでください（二重登録を避けるため）。

## 作り方（スクリプト）

`tools/make_meishi_import.py` は、CSVと画像フォルダからこの形式のZIPを作ります。Python 3の標準機能だけで動きます。

```bash
# 画像のファイル名がCSVの列の値で決まっている場合（例：名刺ID_1.jpg が表、名刺ID_2.jpg が裏）
python tools/make_meishi_import.py eight.csv --images ./eight_images \
    --front "{名刺ID}_1.jpg" --back "{名刺ID}_2.jpg" -o meishi-import.zip

# CSVに既に「表面画像」「裏面画像」列（ファイル名）がある場合
python tools/make_meishi_import.py cards.csv --images ./images -o meishi-import.zip
```

- `{列名}` には、その行のその列の値が入ります。
- 画像は `--images` フォルダの中をサブフォルダまで、ファイル名（大文字小文字は区別しない）で探します。
- 見つからなかった画像は一覧で表示します。その人は画像なしで取り込まれます。
- ZIP内の画像名は連番に付け替えます（日本語のファイル名でも問題が起きないように）。

できたZIPをGoogle Driveやスマホに置き、アプリの「Eightなどからインポート」で選んでください。
