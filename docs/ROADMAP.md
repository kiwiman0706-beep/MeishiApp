# 次の改善候補

初版では、個人用の画像・連絡先・メモ・録音管理を優先しています。

1. 画像内の複数名刺の人物別分割。輪郭検出・台形補正・切り抜きは0.2.0でGoogle ML Kitスキャン撮影に追加済み。
2. Google連絡先の既存人物選択、差分更新、手動統合。二重登録のより詳しい候補表示。
3. ユーザー本人のOAuth設定を使ったGoogle Drive定期バックアップ。複数端末同期は衝突解決を設計してから。
4. スキャン用フォルダのバックグラウンド監視。PC側取り込みツールやNAS/SMB接続。
5. 公開サイトの人物写真・会社ロゴ候補をアプリ内に表示し、出典付きで選択・登録。
6. 録音の文字起こし・要約（明示的な送信操作と確認を設ける）。
7. XLSX出力、添付画像入りExcel、vCard出力、CSV入出力。
8. 暗号化ZIP、アプリの生体認証ロック、バックアップ世代管理。
9. 大量データ向けSQLite移行と、長時間処理のキャンセル・再開。
10. Android 8/最新OS、Samsung/Nothing/タブレットでのカメラ・着信画像・フォルダプロバイダ差を確認。

着信画面の見え方そのものは、このアプリでは制御できません。
