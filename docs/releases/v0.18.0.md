## この版の変更

- **名刺のQRコードを読み取りに使う**：QRコードのある名刺は、アプリがQRコードを読み取り、その内容をGeminiに伝えます。メールアドレス・電話番号・URLはQRコードの正確な文字を使うので、小さな文字の読み違い（「qn」と「gn」など）が直ります。vCard形式のQRコードなら、空欄の氏名・会社・住所なども埋めます。読み取ったQRコードの内容は「名刺の全文」に残り、検索できます。
- **vCardで送る**：名刺を連絡先ファイル（.vcf）にして、LINE・Gmail などで送れるようにしました。
  - 1件：名刺の「⋯」→「vCardで送る」。
  - 複数件：一覧の「選択」で名刺を選び（「表示中をすべて」も可）、「vCardで送る」。1つのファイルにまとめて送ります。
  - 受け取った人はそのまま連絡先に追加できます（氏名・読み・会社・部署・肩書き・電話（会社・携帯・FAX）・メール・住所・URL、交換日のメモ）。
  - Windows/Mac では .vcf ファイルを保存してフォルダを開きます（Gmail などで添付してください）。
