Theta Meishi Hatch の最初の公開版です。スマホ（Android）とパソコン（Windows / Mac）で、同じ名刺データ（Googleドライブの「Theta Vault」フォルダ）を使います。

## ダウンロード

| 端末 | ファイル |
| --- | --- |
| Android 8以上 | `theta-meishi-hatch-0.14.0.apk` |
| Windows 10 / 11 | `ThetaMeishiHatch-Setup-0.14.0.exe`（インストーラー。以後は自動で更新） |
| Mac（Appleシリコン M1〜） | `ThetaMeishiHatch-0.14.0-mac-arm64.dmg` |
| Mac（Intel） | `ThetaMeishiHatch-0.14.0-mac-x64.dmg` |

- Windows：署名していないため、SmartScreenが出たら「詳細情報」→「実行」。
- Mac：初回だけ、アプリを右クリック →「開く」（macOS 15以降は「システム設定」→「プライバシーとセキュリティ」→「このまま開く」）。
- Android：ブラウザでAPKを開き、「この提供元のアプリを許可」してインストール。

## 主な機能

- 撮影 → Geminiで読み取り → Google連絡先へ自動登録（バックグラウンド・まとめて撮影）。名刺画像を連絡先の写真に。
- Googleドライブ（ScanSnapのPDF）、画像・PDF、ZIP（Eightの画像ZIPなど）からの一括取り込み。
- 一覧・表・カレンダー（名刺交換日、Googleカレンダー登録）・地図・**会社一覧（名刺から切り出したロゴ）**。
- 重複の検出と一括統合（名刺どうし、既存のGoogle連絡先とも）。会社の代表番号だけの一致は重複にしない。
- 年賀状・暑中見舞い・クリスマスカード・手紙・書類の管理。お店のカード。
- やり取りのメモ・録音。
- データは Theta Vault（Obsidianで開けるMarkdown＋画像）。Googleドライブで同期。
- Androidのホーム画面ウィジェット（最近登録・最近開いた名刺）。
- パソコン版はトレイ常駐。DeskHatchの「Webページ」ドロワーにも表示できる。

## この版での変更

- Google連絡先に姓・名と読み仮名を分けて登録（Googleコンタクトで「よみがな」が出る）。読み取り済みの名刺の読み仮名を補う機能。
- 更新のお知らせ：Androidは新しい版があるとホーム画面に表示、Windowsは自動でダウンロードして次の起動時に更新、Macはお知らせしてダウンロードページを開く。
- Windowsのインストーラー。
