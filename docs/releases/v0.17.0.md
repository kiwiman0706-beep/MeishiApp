## この版の変更

- **手書きメモ**：名刺の詳細の「やり取りのメモ」に「手書き」ボタンを追加しました。Galaxy の Sペン、Windows のペン、iPhone/iPad の Apple Pencil、指やマウスでも書けます。
  - ペンの筆圧で線の太さが変わります。ペンを一度使うと、指や手のひらでは書かずに紙のスクロールになります（「指でも書く」で切り替え）。
  - Sペンのサイドボタンを押しながら、またはWindowsのペンの消しゴム側でなぞると消えます。消しゴム・元に戻す・やり直す、4色・3つの太さ、「下に書き足す」。
  - 保存した手書きはタイムラインに画像で表示し、あとから書き足せます。Theta Vault では画像付きのメモとして保存するので、Obsidian でも見えます。
  - 「保存後に文字にする」をオンにすると、Gemini が手書きの文字を書き起こし、検索できるようになります（1件 1円未満の目安）。
- 0.16.0 のシリーズの設定の引き継ぎもご覧ください。
