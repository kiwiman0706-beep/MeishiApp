## この版の変更

- **Theta Hatch シリーズの設定の引き継ぎ**：Geminiのモデル、Googleアカウント、カレンダーの登録先などを、Googleドライブの Theta Vault（`.theta/settings.json`）を通じてシリーズの他のアプリと共有できるようにしました。
  - 他のアプリの設定が見つかると、ホームに「シリーズの設定を引き継ぐ」が1度だけ出ます。項目ごとに選べ、選ばなかった項目はこのアプリだけの設定のままです。
  - メニュー →「Theta Hatch シリーズの設定」で、項目ごとに「シリーズ共通」と「このアプリだけ」を切り替えられます。共通の項目は、どのアプリで変えても他のアプリに反映されます。
  - APIキーはドライブに置きません。Androidでは、同じ端末のシリーズのアプリに登録済みのキーがあれば「Gemini APIキー・モデル」の画面からコピーできます（貸した側には通知が出ます）。
- Windows/Macでは起動時と設定の変更時、Android・Web版ではドライブ同期のたびに確認します。
