## この版の主な変更

### 会社ロゴを自動で
- 名刺を読み取ると、**名刺にあるロゴを同時に切り出して保存**します（Geminiへの問い合わせは1回のまま）。
- 名刺にロゴが無いときは、**会社のウェブサイトからロゴを取得**します（名刺のWeb欄、無ければ会社のメールアドレスのドメインからサイトを特定。どちらも無い会社は、メニューの「ロゴの無い会社」でGeminiのGoogle検索を使って公式サイトを探します）。
- ロゴの出どころ（名刺から／サイトから／手動）を記録し、会社一覧に表示。名刺から切り出したロゴはサイトのロゴより優先、手で選んだロゴは自動で置き換えません。

### Androidも自動更新
- 新しい版をWi-Fiで先にダウンロードし、お知らせを押すとアプリ内で更新します。Android 12以降は、一度この方法で更新すると、次からはアプリを閉じている間に自動で更新されます（初回だけ「この提供元のアプリを許可」が必要）。

### iPhone向けのWeb版（PWA）
- `https://kiwiman0706-beep.github.io/MeishiApp/` をSafariで開いて「ホーム画面に追加」。App Storeや開発者登録なしで使えます。
- 撮影・写真から取り込み → Geminiで読み取り → Google連絡先へ登録、一覧・会社一覧・地図・年賀状。Googleドライブの Theta Vault で他の端末と同期。
- 初期設定は `docs/WEB_SETUP.md`（Web用のOAuthクライアントIDが必要）。
