# Google Drive連携の初期設定（1回だけ）

Theta Meishi HatchがGoogle DriveのScanSnapフォルダを読み、取り込み済みのPDFを「登録済み」フォルダへ移動するには、Google Cloudに「このアプリからのDriveアクセス」を登録する必要があります。料金はかかりません。PCのブラウザで作業してください（10分程度）。

## 1. プロジェクトを作ってDrive APIを有効にする

1. https://console.cloud.google.com/ を開き、名刺に使うGoogleアカウントでログインします。
2. 上部のプロジェクト選択 →「新しいプロジェクト」→ 名前は `meishi-claude` などで作成します。
   - Gemini APIキーを作ったプロジェクトがあれば、それを使っても構いません。
3. 「APIとサービス」→「ライブラリ」→ **Google Drive API** を検索して「有効にする」。

## 2. OAuth同意画面（Google Auth Platform）

1. 「APIとサービス」→「OAuth同意画面」（または「Google Auth Platform」）を開き、「開始」。
2. アプリ名 `Theta Meishi Hatch`（既に `Meishi-Claude` で作った場合はそのままで動きます）、サポートメールに自分のアドレス。
3. 対象（ユーザーの種類）は **外部**。
4. 「対象」→「テストユーザー」に**自分のGoogleアカウント**を追加します。
5. 公開ステータスは「テスト」のままで構いません（自分だけが使うため）。

## 3. Android用のOAuthクライアントを作る

1. 「クライアント」（または「認証情報」→「認証情報を作成」→「OAuthクライアントID」）。
2. アプリケーションの種類：**Android**
3. パッケージ名：`jp.yaegaki.meishiclaude`
4. SHA-1証明書フィンガープリント：

   ```
   A1:13:EA:34:83:60:56:32:E7:F5:94:4E:4E:8C:20:55:DD:AE:28:BA
   ```

   （アプリの署名鍵 `meishiclaude-release.jks` のものです。鍵を作り直した場合は `keytool -list -v -keystore meishiclaude-release.jks` で表示されるSHA1に変えてください。）
5. 作成。クライアントIDをアプリに入力する必要はありません（パッケージ名と署名でGoogle側が判別します）。

反映まで数分かかることがあります。

## 4. アプリ側

1. メニュー →「Google DriveのScanSnapフォルダを設定」。
2. 初回だけGoogleの許可画面が出ます。「このアプリはGoogleで確認されていません」と表示されたら「続行」（自分で作ったアプリのため）。Driveへのアクセスを「許可」。
3. フォルダをたどってScanSnapの保存先を開き、「○○を使う」。まとめ方は「1ファイル = 1人」（表裏を1つのPDFにしている場合）。
4. 以後はホーム画面の「Google Driveから取り込む」を押すだけです。
   - 新しいPDFを取り込み → 自動でGemini読み取り → 取り込みが済んだPDFは同じフォルダ内の「登録済み」へ移動（無ければ作成）。
   - 一覧が「要確認」で絞り込まれるので、1人ずつ開いて「保存して連絡先に登録」。

## 補足

- 許可する範囲は「Google Drive全体」です。ScanSnapが作ったファイルを移動するのに必要なためです。アプリが触るのは選んだフォルダとその「登録済み」フォルダだけです。
- 「テスト」状態のアプリは、Googleの仕様で**7日ごとに許可が切れる**ことがあります。その時は取り込みボタンを押すと許可画面がもう一度出るので、「許可」を押してください。
- 取り込めなかったPDF（壊れている等）は移動せず、フォルダに残します。
- 既に取り込み済みの内容と同じファイルは二重登録せず、「登録済み」へ移動だけします。
