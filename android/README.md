# Meishi-Claude 0.7.0（名刺ノート Claude版）

## 0.7.0の変更点

- **ZIPから一括取り込み**（メニュー）：名刺画像だけのZIPに対応。Eightの画像ダウンロード（`交換日_氏名_会社_ID.jpg`、裏は `_裏`）は表裏を自動でまとめ、氏名・会社・交換日をファイル名から入れてから、Geminiで残りを読み取ります。WindowsのZIP（Shift_JISのファイル名）も可。取り込み分だけ「連絡先へ自動登録」のオン・オフを選べます（既定はオフ）。
- Geminiの読み取り結果は、読めた項目だけを反映（空欄で既存の値を消さない）。


## 0.6.0の変更点

- **Google Drive同期**：メニュー →「Google Driveで同期を始める」。マイドライブの「Meishi-Claude データ」フォルダに、名刺（1人1ファイル）・画像・PDF原本・メモ・録音を同期します。アプリを開いた時・離れる時・読み取り後に自動で同期し、「今すぐ同期」もできます。両方の端末で同じ人を編集した場合は、新しい方の内容を優先し、メモ・画像・録音は両方残します。仕様は `../docs/SYNC_SPEC.md`。
- 別の端末で連絡先登録済みの人には「登録済み」と表示し、二重登録しません。


## 0.5.0の変更点

- **登録まで全自動・バックグラウンド処理**：撮影や取り込みが終わるとすぐ一覧に戻り、読み取り → 項目反映 → Google連絡先登録を裏で進めます（通知に進み具合と結果）。待たずに次の名刺を撮影できます。氏名が読めない・読み取りに注意点がある名刺は「要確認」に残ります。アプリが途中で終了されても、次に開いた時に続きから再開します。
- **まとめて撮影**：撮影ボタンの長押し、またはメニューから。「表・裏の順」「片面だけ」で何人分も続けて撮れます。
- **連絡先の修正**：アプリで編集して保存すると、このアプリが登録したGoogle連絡先も更新します。削除時は「名刺と連絡先を削除」も選べます。
- **重複のお知らせ**：同じメール・携帯番号・氏名（＋会社）の名刺や、登録時にGoogle連絡先に既存の人がいた場合、ホームに「重複の可能性」を表示。1人にまとめる（Google連絡先も1件に統合）／別人として扱う／追加した連絡先だけ削除、が選べます。
- **Eightなどからのインポート**：CSV＋名刺画像のZIPを読み込みます。形式は `../docs/IMPORT_FORMAT.md`、作成スクリプトは `../tools/make_meishi_import.py`。
- 初回の撮影時に、連絡先の権限と登録先Googleアカウントを1回だけ確認します。メニューの「読み取り後に連絡先へ自動登録」でオフにできます。


## 0.4.0の変更点

- **Google DriveのScanSnapフォルダから取り込み**：ホームの「Google Driveから取り込む」1回で、フォルダ内の新しいPDF・画像を取り込み、済んだファイルを同じフォルダ内の「登録済み」へ移動します。初回だけGoogle Cloudでの設定が必要です（`../docs/DRIVE_SETUP.md`）。
- **取り込み後に自動で読み取る**：撮影だけでなく、Drive・画像/PDF・フォルダからの取り込みでも、新しい人を続けてGeminiで読み取ります。複数人の場合は終了後に一覧が「要確認」で絞り込まれます。メニューでオフにできます。


## 0.3.0の変更点（ChatGPT版 0.2.0から）

- **別アプリとしてインストール**：package `jp.yaegaki.meishiclaude`、表示名「Meishi-Claude」。ChatGPT版と並べて使えます。データ移行はChatGPT版でバックアップZIPを作り、Meishi-Claudeの「メニュー → バックアップ・復元 → バックアップから復元」で読み込みます（形式は同じ）。
- **撮影から登録までを短縮**：画面下中央の「撮影」→ 表・裏を撮って完了 → 自動でGemini読み取り → 確認画面で「保存して連絡先に登録」。登録先Googleアカウントは初回に選んだものを記憶し、2回目以降は選択画面と確認ダイアログを省略します。連絡先の写真は「名刺の表面」が標準（メニューで変更可）。
  - 0.2.0：取り込み → スキャン撮影 → スキャンを開始 → 撮影 → Geminiで認識 → 料金確認 → 反映して編集 → 確認済みで保存 → Google連絡先 → 写真選択 → アカウント選択 → 確認 → 登録（アプリ側のタップ約12回）
  - 0.3.0：撮影 → 撮影 → 保存して連絡先に登録（初回のみアカウント選択が1回増えます）
- **メニュー整理**：下のタブは「名刺／撮影／メニュー」の3つ。取り込み・一括読み取り・CSV・バックアップ・設定はメニューにリスト形式でまとめました。画像・PDF・ScanSnapフォルダの取り込みは「まとめ方」を選ぶとそのまま開始します。
- **詳細画面**：その時に必要なボタンを1つだけ大きく表示（読み取る／確認して保存／連絡先に登録／連絡先を開く）。その他の操作は右上の「⋯」に移動。画像の回転・並べ替え・共有・解除は画像を開いた画面に移動。電話・メール・Web・住所はタップで発信・メール作成・地図表示。メモと録音は1つの履歴にまとめました。
- 「撮影後に自動で読み取る」はメニューでオフにできます。APIキー未設定時は画像だけ保存されます。

# 以下、0.2.0時点の説明（ChatGPT版から引き継ぎ）

## 名刺ノート / Meishi Note 0.2.0

Android 8.0以上・更新済みのAndroid System WebViewを使う個人向け名刺管理アプリ。利用者同士のネットワーク機能はありません。

## 最初の使い方

1. `meishinote-0.2.0.apk` をAndroid端末にインストールします。端末に求められた場合、そのAPKを開いたアプリに「不明なアプリのインストール」を一時許可します。
2. 「設定・出力」でご自身のGemini APIキーを入力して保存します。キーはAndroid Keystoreを使って暗号化保存し、ソース・APK・バックアップには含めません。
3. 「取り込み」→「スキャン撮影」→「スキャンを開始」。表面→裏面と続けて撮影し、切り抜き・向き・ページ順を確認して完了します。画像・PDFからの取り込みもできます。
4. 「Geminiで認識」→認識結果を確認→「反映して編集」→「確認済みで保存」の順に進みます。
5. 「Google連絡先」で写真欄に入れる画像を選び、Googleアカウントを選択して登録します。
6. 定期的に「設定・出力」からバックアップZIPをGoogle Driveなどの非公開フォルダへ保存します。

初期モデルは `gemini-2.5-flash`。利用できない場合は「モデル一覧」で、ご自身のAPIキーで使える画像入力対応Flash系モデルを選択して保存してください。新しいモデルで出力形式のエラーになる場合は「API互換設定」を切り替えます。API利用料金やGoogle側のデータ利用条件は、各自のプロジェクト設定に従います。

## スキャン撮影（0.2.0で追加）

- 新規は「取り込み」→「スキャン撮影」。既存の人には詳細の「スキャンで追加」。
- 初期設定は **全ページ = 1人**。表→裏→追加資料と撮影し、スキャン画面で完了します。
- 複数人の片面名刺は「1ページ = 1人」、両面名刺は「2ページずつ = 1人」を選びます。後者は表→裏→次の人の表→裏と撮影。奇数枚なら最後の1枚だけで1人になります。スキャン画面で最後に確認した順番を使います。
- Google Play開発者サービスが必要です。初回はスキャン機能のダウンロードに時間がかかる場合があります。公式の対応要件はAndroid 5.0以上・総RAM 1.7GB以上（本アプリ自体はAndroid 8.0以上）。開始できない場合は「通常のカメラ」に切り替えられます。
- 輪郭検出・切り抜き処理は端末上で行います。文字の認識は保存後に「Geminiで認識」を押した時に行います。
- **保存するのはスキャナから返った補正後のJPEGです。切り抜き前のカメラ画像はSDKから受け取れないため保存しません。** 補正後JPEGの原本と表示用画像はアプリ内に残り、バックアップ対象です。全体写真も残したい場合は通常のカメラで追加撮影してください。
- 1画面に並べた複数の名刺を人物ごとに自動分割する機能ではありません。1枚ずつ映して撮影してください。
- 白い机の上では輪郭を判別しにくいことがあります。名刺と色が異なる無地の背景で、反射や影を避けると確認しやすくなります。
- 0.1.0と同じ署名・packageで更新します。アンインストールせず上書きインストールしてください。データ形式は変更していません。

## ScanSnapの使い方と制約

ScanSnapで保存したフォルダを、Androidのファイル選択画面から参照できる状態にしてください。PCのローカルフォルダやSMBのNASフォルダをアプリ単独で直接読む機能はありません。端末へコピーするか、Androidのドキュメントプロバイダとしてフォルダを公開する同期・ファイルアプリ等が必要です。Google Driveがファイル単体の選択にしか対応しない場合は、「画像・PDFを選択」で複数選択してください。

- **1ファイル = 1人**：両面・追加ページを1つのPDFにした場合。
- **2ページずつ = 1人**：表・裏の順で保存した画像群、または表裏が順番に並ぶPDF。
- **1ページ = 1人**：片面名刺が複数ページになったPDF。
- **全ページ = 1人**：複数ファイルを1人にまとめたい場合。

ファイル名順（大文字小文字無視の文字列順）、PDF内はページ順。`1, 10, 2`の並びを避けるには`001, 002...`のゼロ埋め名を推奨します。表裏モードで奇数の最後のページは1ページの名刺として保存します。撮影画像の自動名刺枠検出・台形補正・複数名刺の自動分割は未実装です。ScanSnap側で1名刺ずつ切り出す設定を利用してください。

一括取り込み後は「未認識の名刺を一括認識」を押します。前回のフォルダは再選択せず再取り込み可能で、同一内容のファイルはSHA-256でスキップします。常時監視・自動認識はしません。表裏モードの読込失敗はその回全体を中止して位置ずれを防ぎます。片側だけ既存の組はスキップし、既存の人に手動で追加する案内を表示します。

上限：1回200ファイル、1ファイル100MB、PDF100ページ、フォルダの階層は8段、Geminiは1人20ページ・圧縮後合計12MB、録音は1ファイル512MB。バックアップ・復元は展開後合計2GB、20,000ファイルまで。クラウド上の大量ファイルは端末への事前ダウンロードを推奨します。

## Google連絡先・着信表示

Google OAuthクライアントIDをアプリに埋め込む方式ではなく、Android標準の連絡先データベースとGoogleアカウントの同期を使います。Googleアカウントを端末に追加し、連絡先の同期を有効にしてください。保存成功は端末側の登録成功であり、Google側への同期完了を保証する通知ではありません。

同じ電話番号またはメールがある場合、既存候補を表示して別登録するか確認します。自アプリで登録済みの連絡先は再作成せず開きます。**登録後の自動更新・双方向同期はありません**。Google連絡先の編集は連絡先アプリ側で行います。

名刺を連絡先の写真欄に設定できますが、電話着信時の表示・丸い切り抜き・表示サイズは端末と電話アプリ次第です。文字が読めるサイズになるとは限りません。Google側や端末側の他のプロフィール画像が優先されることもあります。まず1件で確認してください。

人物写真とロゴは、検索を開いて候補を人が選ぶ方式です。自動取得・自動照合は未実装。画像提供元の利用条件を確認してください。

## データ保存と注意

- アプリ専用領域 `files/vault/data.json` と `files/vault/media/` に保存します。アンインストールで消えます。
- JSON更新はAtomicFileを利用。書き込みエラー時は直前のデータへ戻します。
- 録音停止・名刺画像の取り込みはデータを保存してから表示に反映します。強制終了・電源断による録音ファイル破損までは防げません。
- バックアップZIPは暗号化されていません。非公開の保存先へ保存してください。端末内の画像・DBはAndroidのアプリ隔離で保護されますが、アプリ独自のロックはありません。
- 復元は「未登録IDを追加」です。既存の同じIDを古い状態に戻す操作ではありません。現在の内容の上書き復元や端末間同期は未実装です。
- 端末を替えて復元してもGoogle連絡先自体は既にGoogleに残っていることがあります。再登録時の重複に注意してください。
- APIキー、Googleアカウント情報、フォルダアクセス権はバックアップしません。
- 認識中・大量取込・バックアップ中はアプリを開いたままにしてください。端末の強制終了に対するジョブ再開機能はありません。

## 開発・ビルド

Java + Android標準API + Google ML Kit Document Scanner 16.0.0 + 同梱HTML/CSS/JavaScriptのWebView UI。外部の画面やスクリプトはWebViewにロードせず、画像・DBも外部サーバーに預けません。認識時のみGeminiへ送ります。外部画像検索はブラウザで開きます。

- `app/src/main/java/jp/yaegaki/meishinote/`：Android連携と保存。
- `app/src/main/assets/`：日本語UI。
- `tests/ui.test.cjs`：PlaywrightによるUIテスト。
- `tests/android/Smoke.java`：Android上の取込・復元テスト。
- `docs/TESTING.md`：この納品時点の検証状況。
- `docs/ROADMAP.md`：残っている改善候補。

Android Studioでこのフォルダを開けます。JDK17、Android SDK35 / build-tools35.0.0、AGP8.7.3、Gradle8.9を使用。Gradle Wrapperを同梱しています。初回は依存ライブラリを取得するためネット接続が必要です。通常のdebugビルドは `./gradlew :app:assembleDebug`。

納品APKの再ビルドは `build.sh` を使います。

```sh
ANDROID_SDK_ROOT=/path/to/android-sdk \
SIGNING_FILE=/private/path/meishinote-release.jks \
SIGNING_PASS_FILE=/private/path/keystore-password.txt \
./build.sh
```

APK：`build/meishinote-0.2.0.apk`。packageは`jp.yaegaki.meishinote`、versionCodeは2。将来の更新ではversionCodeを増やし、同じ署名鍵を使ってください。

署名鍵はソースZIPに含めず、別の非公開バックアップZIPとして提供します。**署名鍵・パスワードをGitHubへアップロードしないでください。** Android Studioの通常debug署名では、納品APKに上書きインストールできません。同じ署名鍵でrelease APKを生成するか、データをバックアップしてから入れ替えます。
